# Карелия: Живые Тропы (PWA)

Мобильный полевой гид по Республике Карелия: интерактивная карта с кэшированием тайлов и экспортом в GPX/GeoJSON, AR-компас с петроглифами, голосовой аудиогид, конструктор маршрутов, генератор «Живых открыток» и паспорт путешественника.

## Как залить и запустить прямо с телефона через GitHub

1. Открой [github.com](https://github.com) в браузере телефона и войди в аккаунт.
2. Нажми **`+`** -> **New repository**, задай имя (например, `karelia-live-trails`), выбери **Public** и нажми **Create repository**.
3. На странице пустого репозитория нажми **uploading an existing file** (или **Add file** -> **Upload files**).
4. Распакуй архив и загрузи в корень репозитория файлы:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.svg`
   - `icon-512.svg`
   - `.nojekyll`
5. Нажми **Commit changes**.
6. Перейди в **Settings** -> **Pages**, в блоке **Build and deployment -> Branch** выбери **`main`** и папку **`/(root)`**, нажми **Save**.
7. Через 1–2 минуты сайт откроется по адресу:
   `https://<ваш-логин>.github.io/karelia-live-trails/`
8. Открой эту ссылку в Chrome или Safari на телефоне и нажми **«На экран „Домой“» / «Добавить на главный экран»** — приложение установится как PWA и будет работать по HTTPS (нужно для камеры AR, GPS и Service Worker).
